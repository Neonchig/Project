# Server-side

Программа написана на websockets и fastapi, для сокета и api соответственно.
Эндпоинты api - /login (для аутентификации), /register (для регистрации), /refresh (для аутентификации по refresh token), /icon (для иконки вебсайта).
У базы данных нет эндпоинта, работа с ней вызывается напрямую из файла.

Структура .env:

+ ProjPath - путь к директории, где лежит main.py и README.md

+ ServUUID - uuid сервера, на данный момент ипользуется только для генерации jwt

+ Secret = уникальный секретный ключ сервера, длина - 64 символа

## API

| Endpoint  |                                        JSON (Данные)                                        |                                                                                                           Response (Ответ)                                                                                                           |                                                  Краткое описание                                                  |
| :-------: | :-----------------------------------------------------------------------------------------: | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: | :----------------------------------------------------------------------------------------------------------------: |
| /register | {"username": "`[PASSWORD]`", "password": "`[PASSWORD]`", "email": "`[EMAIL, Опционально]`"} |                                                                   {"status": "201", "refresh": "[TOKEN]"} -  при удачном создании; {"status": "500"} -  при ошибке                                                                   | Регистрирует пользователя в базе данных, вся информация, предоставленная в  /register  хранится как учетные данные |
| /refresh  |                { "username": "`[USERNAME]`", "refresh_token": "`[TOKEN]`" }                 | {"status": "422", "message": "..."} - при отсутствии нужных данных; {"status": "401", "message": "..."} - при невалидном токене; {"status": "200", "refresh_token": "[TOKEN]", "bearer": "[TOKEN]"} - при успешном обновлении сессии |   Получает новый сессионный токен по refresh-токену, который выдается при регистрации или при обновлении токена    |
|  /login   |                 { "username": "`[USERNAME]`",  "pasword": "`[PASSWORD]`" }                  |                                                {"status": "401", "message": "..."} -  При неверных учетных данных; {"status": "200", "bearer": "[TOKEN]", "refresh_token": "[TOKEN]"}                                                |                               Получает сессионный и refresh токены по учетным данным                               |
