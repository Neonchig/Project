# Server-side

Программа написана на websockets и fastapi, для сокета и api соответственно.
Эндпоинты api - /login (для аутентификации), /register (для регистрации), /refresh (для аутентификации по refresh token), /icon (для иконки вебсайта).
У базы данных нет эндпоинта, работа с ней вызывается напрямую из файла.<br>
Структура .env:
+ ProjPath - путь к директории, где лежит main.py и README.md
+ ServUUID - uuid сервера, на данный момент ипользуется только для генерации jwt
+ Secret = уникальный секретный ключ сервера, длина - 64 символа

## Тип - message

Формат - {"type": "message", "to": "Username получателя", "message": "Сообщение"}

## Тип - group_message

Формат - {"type": "group_message", "grp_name": "Название группы, в которую нужно отправить сообщение", "message": "Сообщение"}

## Аутентификация

Аутентификация производится по первому сообщению в слкете, формат - {"Authorization": "Bearer {TOKEN}"}, где {TOKEN} - jwt токен, получается при регистрации, авторизации средствами refresh token или логина/пароля

## Test_app

Программа, написанная в качестве тестового клиента. Возможности:
+ Имитация цепочки аутентификации (jwt -> refresh token -> username + password)
+ Имитация цепочки аутентификации, минуя jwt (refresh token -> username + password)
+ Имитация цепочки аутентификации только по username + password
+ Имитация запроса с недействительными данными (Тест отказа в подключении)
+ Регистрация нового пользователя
+ Создание новой группы
